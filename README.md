# DeskDeflect

> Async inbox that handles admin tasks so developers never break deep work.

## What is DeskDeflect?

DeskDeflect is built for **Software developers and knowledge workers who lose focus managing appointment scheduling, expense submissions, vendor emails, and other admin tasks that interrupt coding or deep work sessions**. Framing as 'admin firewall' rather than productivity app — it removes tasks from your plate entirely rather than organizing them. Developers are vocal about this pain and share tools virally.

### Core MVP features
- Unified async inbox: forward any admin email/task here instead of handling it live
- AI agent classifies, drafts responses, and flags only items requiring a real decision
- Calendar scheduling handled automatically via natural language rules ('never before 10am, no back-to-backs')
- Daily digest: 5-minute review of what was handled and what needs a yes/no
- Integrations: Gmail, Outlook, Calendly-style scheduling, Slack

**Pricing:** Monthly subscription per seat at $19/month individual · $49/month team of 3

## How this business runs itself (mailbox money)

The goal is passive, low-maintenance recurring revenue: AI is how we build and operate the business, not necessarily what it sells.

Gmail/Outlook webhook pushes every incoming email to the classification pipeline instantly. OpenAI GPT-4o categorizes as 'auto-handle,' 'draft-and-confirm,' or 'escalate.' Auto-handle items (spam, newsletters, vendor acknowledgments) are responded to and archived with no human touch. Draft-and-confirm items queue for the daily digest. Calendar invites resolved against stored scheduling rules via Google Calendar API. Stripe manages subscriptions with zero manual billing. AI support agent handles onboarding questions. Owner time: ~1 hour/week reviewing edge-case escalations.

**Estimated owner time:** ~1 hour(s)/week

**MVP estimate:** Next.js + Supabase + OpenAI + Gmail API + Google Calendar API; 3.5 weeks solo dev for inbox routing, AI classification, and digest generation
